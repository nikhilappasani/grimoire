# Source Documents

Documents supplied by the user during an interview, stored as provided. Concepts in `knowledge/` link
here; the bundle itself stays distilled rather than duplicating whole documents.

Kept as plain markdown with YAML frontmatter and relative links, so a personal knowledge vault can
consume this folder directly without conversion.

Nothing classified `confidential`, and nothing containing secrets or personal data, is ever stored
here — those are linked at their source. See
`skills/loreweaver/references/KNOWLEDGE-CAPTURE-OKF.md` §7.

This directory is the **default** `docs` root. Override with `GRIMOIRE_DOCS_ROOT` or `roots.docs` in
`grimoire.config.json`.
