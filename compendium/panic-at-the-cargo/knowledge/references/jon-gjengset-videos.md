# Jon Gjengset — YouTube Channel

Channel: <https://www.youtube.com/@jonhoo>. Free. Long-form (1–8 hour) live coding sessions.

## When PAC should cite this

- When a learner wants to see a complex Rust concept worked through end to end in real code
- When written explanations of async, iterators, or trait internals aren't landing
- Cite as: "Jon Gjengset has a deep-dive video on [topic] — search his channel for '[keyword]'."

## Notable series and videos

| Video / Series | Topic | Best for |
| --- | --- | --- |
| Crust of Rust | One concept per episode (lifetimes, iterators, smart pointers, etc.) | Intermediate learners hitting one specific wall |
| Implementing a HashMap | Hash maps, hashing, unsafe | Understanding `HashMap` from the inside |
| Decrusting the standard library | `Arc`, `Mutex`, `RwLock` internals | Concurrency mental models |
| Async Rust from scratch | Futures, `Poll`, `Waker`, `Pin` | Learners starting async projects |
| `tokio` deep dives | Async runtime internals | Advanced async projects |

## Usage note

Videos are long — point learners to the specific series or topic, not the full channel.
The *Crust of Rust* playlist is the best starting point for intermediate concept gaps.
