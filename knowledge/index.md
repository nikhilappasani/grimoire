# Knowledge Base

Entry point for the OKF bundle. Concepts are added by `loreweaver` as interviews are completed.

Layout, per `skills/loreweaver/references/KNOWLEDGE-CAPTURE-OKF.md` §2:

```text
knowledge/
├── index.md        this file
├── glossary/       Glossary Term concepts
├── policies/       Policy concepts
├── playbooks/      Playbook and Runbook concepts
└── log.md          chronological change history (optional)
```

One concept per file. The file path is the concept's identity — moving a concept breaks every link to
it.

This directory is the **default** `knowledge` root. Point `GRIMOIRE_KNOWLEDGE_ROOT` or
`roots.knowledge` in `grimoire.config.json` at a separate knowledge-base repository to use that
instead.
